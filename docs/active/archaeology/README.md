# Active Archaeology

This directory holds archaeology reports for UI-facing semantic claims that must
be traced back to real typed carriers before `ploke-egui` presents them as
debugger facts.

- [`INDEX.md`](INDEX.md)
  Coverage table for current archaeology reports, chosen primary carriers, and
  downstream consumers.
- [`ploke-tree-graph/README.md`](ploke-tree-graph/README.md)
  Reports for claims backed by `ploke_tree::Graph` carriers and projections.
