# Worker Packets

Shared packet material for `ploke-egui` task-readability workers.

- [`shared-brief.md`](shared-brief.md)
  Common grounding for all workers: objective, graph-boundary rule, no-goals,
  verification expectations, and report format.
- [`templates.md`](templates.md)
  Lane-specific prompt templates for retainer, projection, diagnostics, layout,
  snapshot/docs, graph-gap, and reviewer workers.

Generated packets from `target/debug/xtask orchestrate packet <worker-id>` are
live board artifacts and should not be copied here unless they become durable
handoff evidence.
