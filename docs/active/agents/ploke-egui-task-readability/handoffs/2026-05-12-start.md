## Hard Rule

`ploke-tree::graph::Graph` is the semantic authority.

`ploke-egui` must use references into `ploke_tree::Graph` for semantic access.
Any allocated semantic value cloned out of `Graph` is a phase-stopping blocker.

Invalid patterns:

- copied graph ids/refs/records stored for later semantic use,
- egui-owned `Artifact`, `Runtime`, `Patch`, `Candidate`, `Selection`, or
  `History` mirrors,
- wrapper report/status/info/summary/payload types that merely repackage graph
  facts,
- mirror structures used to avoid borrow-checker pressure.

Allowed values:

- positions,
- rectangles,
- curves,
- collision counts,
- rank/subtree statistics,
- visibility scores,
- color choices,
- render-only strings that cannot recover semantic identity.

Every phase must include a reference-boundary audit. A phase that passes tests
but violates this rule has failed.

## First Wave

Start with measurement before layout tuning.

Recommended lane order:

1. Retainer: locate active projection/geometry/snapshot code and identify
   existing semantic clones in the active egui path.
2. Projection worker: introduce only borrowed projection structure needed for
   diagnostics.
3. Diagnostics worker: add rank spacing, selected-path straightness/visibility,
   and subtree-overlap metrics.
4. Snapshot/docs worker: persist the new view diagnostics and ranked findings.
5. Reviewer: run the reference-boundary audit and task-readability review.
6. Layout worker: tune layout only after diagnostics produce actionable signals.

## Immediate Commands

Use bounded status:

```bash
target/debug/xtask orchestrate --format json status | jq '{
  board,
  blockers: (.blockers | length),
  lanes: [.lanes[] | {id, owned_edit}],
  workers: [.workers[] | {id, role, active}],
  tasks_by_state: (.tasks | group_by(.state.state) | map({
    state: .[0].state.state,
    count: length
  }))
}'
```

Use bounded verification:

```bash
cargo check -p ploke-egui 2>&1 | tail -n 80
cargo test -p ploke-egui <test-filter> 2>&1 | tail -n 80
```

## Do Not Do

- Do not tune from screenshots first.
- Do not create another semantic graph in `ploke-egui`.
- Do not copy ids or records out of `ploke_tree::Graph` as a convenience.
- Do not treat diagnostic snapshots as persisted loop facts.
- Do not broaden into provider/tool/database/timeline drilldown work during the
  first artifact-readability wave unless explicitly opened as a separate lane.
