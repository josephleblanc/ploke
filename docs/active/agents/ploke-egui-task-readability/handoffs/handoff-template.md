# Worker Handoff Template

Use this when refreshing a worker or closing a stale sub-agent.

```text
Worker:
Lane:
Date:

Task:

What I verified:
- file:line
- claim
- command

What I changed:
- file:line
- summary

Boundary risks:
- none / list exact risks

Blockers:
- blocker
- evidence
- next action

Recommended successor prompt:
- concise task
- allowed edit surfaces
- forbidden edit surfaces
- verification command
```
