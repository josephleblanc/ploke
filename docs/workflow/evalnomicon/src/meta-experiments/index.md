# Meta-Experiments

This section collects semi-structured writing about inward-facing methodology
experiments.

Examples include:

- comparing review procedures or prompt variants
- testing new metrics or metric families
- evaluating process choices
- exploring how to make latent gradients more visible

Durable conclusions should be promoted into `core` or `protocols` when they
stabilize.
