# ploke-egui Profiling

This directory tracks how `ploke-egui` measures application performance and
which changes helped or hurt the measured baseline.

- [`setup.md`](setup.md)
  How profiling is enabled, what the app instruments, and how to write rolling
  local performance logs.
- [`performance-change-log.md`](performance-change-log.md)
  Short record of performance-affecting changes and their observed impact.
