# ploke-eval Manual

This mdBook is the implementation and operator manual for `ploke-eval`.

Use it for:

- running `ploke-eval` commands;
- understanding the local artifact layout under `~/.ploke-eval/`;
- operating and debugging Prototype 1;
- finding current source anchors, record surfaces, knobs, and runtime invariants.

For conceptual eval framing and methodology, use the companion
[Evalnomicon](../../../docs/workflow/evalnomicon/README.md). In short:

> Evalnomicon explains why the system exists and what the concepts mean. This
> manual explains how the current `ploke-eval` crate works and how to operate it.
