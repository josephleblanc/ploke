# Glossary

Short working definitions for this manual.

- **Artifact:** a checkout/file state that can hydrate a runtime.
- **Runtime:** an executing `ploke-eval` binary hydrated from an artifact.
- **Parent:** the current runtime with authority to run one Prototype 1 parent turn.
- **Child:** a bounded descendant runtime spawned to evaluate a candidate artifact.
- **Successor:** the selected descendant runtime after handoff validation.
- **History:** sealed lineage-local authority records for handoff and succession.
- **Crown:** lineage-local mutation authority; not a process id, branch, or path.
- **Projection:** a derived operational view such as scheduler state, branch registry, or CLI output.
- **Run profile:** the admitted TOML profile that binds target, model, generation, selection, execution, and control policy.
