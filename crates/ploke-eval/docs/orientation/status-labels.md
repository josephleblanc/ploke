# Status Labels

Prototype 1 docs should label architectural claims when the enforcement level
matters.

- **Implemented:** enforced by current code.
- **Partially implemented:** current code enforces part of the claim, with named gaps.
- **Intended:** target architecture not yet enforced.
- **Not claimed:** a tempting stronger interpretation the project explicitly does not rely on.

Use these labels especially for typestate, History/Crown, child authority,
selection, persistence, and observability claims.
