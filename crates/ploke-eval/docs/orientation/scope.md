# Scope

This book is crate-local documentation for `ploke-eval`.

It should contain current, implementation-adjacent material:

- command workflows;
- persisted file and artifact layouts;
- Prototype 1 operator procedures;
- source maps and implementation anchors;
- runtime knobs and operational tuning notes;
- debugging and recovery notes that depend on current code behavior.

It should not become the live control plane or experiment ledger. Active run
state, handoffs, and rolling work records remain under `docs/active/` and raw
artifacts remain under `~/.ploke-eval/`.
